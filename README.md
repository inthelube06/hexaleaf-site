# hexaleaf.app

Suggested repo name: hexaleaf-site (public).

Static site for Hexaleaf, served by GitHub Pages.

- `index.html` home, `privacy/` privacy policy, `support/` support page, `404.html`
- `CNAME` holds the custom domain; `.nojekyll` tells Pages to serve files as-is
- Yellow `[ ... ]` marks are blanks to fill before launch

Apple URLs for App Store Connect:
- Privacy Policy URL: https://hexaleaf.app/privacy/
- Support URL: https://hexaleaf.app/support/
- Marketing URL: https://hexaleaf.app/
